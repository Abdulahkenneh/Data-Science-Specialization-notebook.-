# Capstone Dataset

## Bike Sharing (hourly)

- Source: UCI Machine Learning Repository, Bike Sharing dataset, file `hour.csv`
- Original authors: Hadi Fanaee-T et al., Laboratory of Artificial Intelligence and Decision Support, University of Porto
- DOI: https://doi.org/10.24432/C5W894
- Dataset record: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Local file: `bike_sharing_hour.csv`
- Original observations: 17,379 hourly records from the Capital Bikeshare system in Washington, D.C., 2011-2012

Please retain this attribution when sharing adaptations. This is historical educational data, not current operational demand data. It contains no missing values in the source release. Column definitions are available in the UCI dataset documentation.

For the platform's inline lesson editor, attach this CSV as the topic dataset: the runner exposes uploaded CSV content as `data.csv`, regardless of the uploaded filename. In a downloaded notebook environment, either place the file in the notebook's `datasets/` directory and read `datasets/bike_sharing_hour.csv`, or rename it to `data.csv` and use the course editor's same example.
